# VYNTRA Legal Documents

This folder contains the product-facing legal documents bundled with the
desktop installer.

These documents are written as a global baseline. Customer contracts, local
jurisdiction annexes, retention periods, privacy contacts and labor-law notices
must be reviewed before rollout in each country.

Bundled files:

- `terminos-condiciones-es.md`
- `terms-conditions-en.md`
- `aviso-consentimiento-empleado-es.md`
- `employee-monitoring-notice-en.md`
